# CEGE 8211: Traffic Flow Theory

Code for the dynamic network loading homework. You can do the homework in either language:

- [`java/`](java): the Java version, a NetBeans project. Open the `java` folder as the project.
- [`python/`](python): the Python version. See [`python/README.md`](python/README.md).

Both versions contain the same networks, the same homework test files (`HW*.txt`), and the same
autograder, which compares your results to the answers in `networks/<name>/solution.txt`.
